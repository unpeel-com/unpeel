# Markdown editor demo

Open this file automatically when you run the app with no arguments.

Click to place the cursor. Drag to select. Double-click a word, triple-click a line. Shift+arrows still work. **Backspace** deletes the selection, or the character before the cursor.

# Change

- [ ] asdfsadf

## Try blocks

On an empty line, type `/` for headings, lists, to-dos, quotes, code, or a divider.

Type `[] ` to start a to-do. Click the box or press ⌘↩ to check it off.

- Enter on this line continues the list
- Enter on an empty item exits it

### Smaller heading

Body text can be *italic*, **bold**, or `inline code`.

## Lists and quotes

- Select a word with Shift+Right
- Cut with ⌘X or Ctrl+X, paste with ⌘V or Ctrl+V
- Undo with ⌘Z or Ctrl+Z
