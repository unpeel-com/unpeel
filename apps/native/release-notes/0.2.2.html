Unpeel 0.2.2

  • One browser window per project — Browser MCP sessions in the same project now share one managed window, with a pinned tab for each session. Logins and project context carry across those tabs while each agent keeps its own target.
  • Workspaces are easier to recognize — each local workspace can carry its own App color across the whole window.
  • External worktrees appear automatically — worktrees created outside Unpeel are discovered beneath their parent project without needing to add them by hand.
  • More control over a busy sidebar — choose how many recently stopped sessions each group previews, and enjoy faster rescans and rendering in large workspaces.
  • Claude subagent lists stay passive — progressive selector repaints no longer look like a new approval prompt or incorrectly mark a session as needing attention.
