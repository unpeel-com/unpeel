Unpeel 0.1.0-beta.16

  • macOS 13 (Ventura) is now supported — the minimum system version dropped from macOS 14 to 13.

Also new since beta.12

  • Profiles (experimental) — run multiple fully isolated Unpeel instances, each with its own sessions, settings, and phone pairing. Enable in Settings ▸ Experimental.
  • Multiple Macs on iPhone — the iOS app (TestFlight build 6) can pair with and switch between several Macs.
  • Archive sessions — a non-destructive way to clear out finished sessions; restore + restart resumes the exact conversation. Old idle sessions can auto-archive (Settings ▸ Advanced).
  • Session control approvals — when one agent tries to type into an unrelated session, Unpeel now asks you first (Settings ▸ Sessions MCP).
  • Faster image gallery on the phone (downscaled thumbnails instead of full-size screenshots).
  • Fixes: stale Codex hook cleanup, settings UI polish, download range handling.
