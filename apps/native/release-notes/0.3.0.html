Unpeel 0.3.0

  • Run several sessions side by side. Split Pane creates a persistent recursive layout for up to eight independent Sessions. Split right or down from any pane header, mix rows and columns, resize or equalize branches, zoom one pane, and close the view without stopping the Sessions.
  • A more tactile sidebar. Session cards lift above the terminal, follow the pointer, spring into folders, and reveal animated pane drop zones without crossing pinned-section boundaries. Pin and Unpin live quietly in row context menus, while pinned Sessions and groups keep passive inline indicators. A collapsed pane row reflects activity from every member, so a working secondary pane never looks idle.
  • Make the window yours. Appearance settings now control background and terminal-surface opacity and tone, including native desktop blur and a flat single-color option. Workspace App colors continue through the full window without recoloring terminal text, while near-white light surfaces stay clean instead of becoming colored paper. Every Settings section now has its own glass-gradient icon.
  • One browser window per project. Browser MCP Sessions in the same project share one managed browser window, with a pinned tab for each Session. Logins and project context carry across those tabs while Sessions keep their own agent-facing targets.
  • A visual designer, directly in the terminal. The new standalone unpeel-design preview turns local HTML and Tailwind files into GPU-rendered artboards inside Kitty-graphics terminals such as Unpeel and Ghostty. Pan and zoom, add and reorder artboards or elements, drill into layers, edit durable project tokens, and compose reusable components with props and slots. Supported property and text edits write straight back to the source files, while external file changes reload live. Its checksum-verified distribution lane is ready to publish independently from the app.
  • Apps now feel native throughout Unpeel. Installed App manifests can declare detection aliases and a brand color, so an App launched from a preset or typed into any terminal is recognized automatically across the Mac app, terminal UI, and phone. App-reported activity, attention, status, and the document it is showing flow into the ordinary Session row and notifications; a title you set yourself always wins. Agents can discover installed Apps and their skills, identify an App in an adjacent pane, and inspect its declared tools. A registry-driven, checksum-verified install lane serves every App from /install/<app>/install.sh; declared tool execution still waits for the Host worker.
  • Stopped and archived finally mean different things. A Session that exits or crashes stays visible and recoverable; only an explicit Stop and archive files it in the Archive. Resume and archive appear only when that exact Session has resumable state.
  • Activity reflects agents, not noisy terminals. Shells, servers, builds, pagers, and repainting TUIs stay visually idle, while recognized foreground agents still report useful activity. Claude's progressive subagent-selector repaints also stay passive instead of looking like a new approval prompt.
  • Terminal interaction is closer to Ghostty everywhere. Desktop rendering, sizing, focus, and scrolling received a broad parity pass. On iPhone and iPad, pointer input is modeless, long-press text selection no longer pulls open the sidebar, and mouse-aware TUIs gain horizontal wheel gestures and pinch zoom. Pinned groups rise above ordinary rows, and pane children sit beneath their main Session with a clear indent.
  • External worktrees appear automatically. Worktrees created outside Unpeel are discovered under their parent project, so they no longer need to be recreated or added by hand.
  • The workspace Controller preview took a major step. In Unpeel Dev, local workspaces, paired Macs, and SSH Hosts share one in-window scope, warm background state, workspace switching, and the same multi-pane presentation. The sidebar and Settings share one workspace picker that identifies the default workspace; local workspaces can open in their own windows, swipe previews retain each workspace's pane groups, and the window follows a selected local workspace's appearance. Appearance edits another local workspace's full look live, Advanced edits a selected local or SSH Host's cleanup behavior through the typed Host protocol, and Presets manages that Host's launch commands over the same connection. A connected phone can also switch among the workspaces served by its Mac.
  • The terminal UI keeps pace. Its pane tree supports the same recursive layouts and interactions, and local or remote Session context menus expose the same gated Rename, Pin/Unpin, Resume, Stop and archive, and Remove actions.
  • Graphics survive the terminal UI. Kitty graphics from the selected live Session now pass through into the correct pane, so visual tools such as Surface and icat can render when Unpeel is running inside Ghostty, kitty, or Herdr.
  • Smaller fixes add up. The full-page Session launcher now fits short preset lists, Cursor sessions recover their MCP identity through wrapper processes, Resume/Archive controls require real conversation evidence instead of guessing from a command name, non-resumable Sessions disappear from pane layouts as soon as they are removed, transcript context menus target the Session you actually clicked, Settings titles follow workspace renames and removals immediately, and the TUI's initial unread receipt now follows the authoritative sidebar selection without leaving a stale dot.
