Unpeel 0.1.0-beta.20

  • No more fish terminal-compatibility warning — fish probes the terminal at startup (Primary Device Attributes) and nothing answered until a window attached, so every new session showed a "could not read response… after waiting for 2 seconds" warning and fish disabled some features. The session host now answers the probe immediately, so fish starts clean with all features on.
  • The Default editor picker now recognizes Zed Preview (and Nightly/Dev builds), not just stable Zed.
