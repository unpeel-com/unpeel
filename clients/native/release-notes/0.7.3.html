Unpeel 0.7.3

  • Approval prompts in every workspace. When an agent in a workspace other than Personal asked to type into another session, the prompt never appeared: the request timed out after two minutes and the agent was told you had declined. Scoped workspaces now show the prompt within a couple of seconds, on the target session's pane, and a prompt nobody answers is reported to the agent as unanswered rather than declined.
  • Your workspace comes back on relaunch. Quitting while scoped to another local workspace reopens in that workspace, the way a selected Host already did.
  • Folder colors in scoped workspaces. Colors chosen on projects of another local workspace now show up (contributed by anilsenay).

Also in 0.7.2

  • OpenCode no longer freezes the app on macOS 15. Starting an opencode session pinned the main thread at 100 % while resolving the OpenCode theme (the config lookup walked past / forever on macOS 15 Foundation) and the app had to be force quit. The lookup is finite now.
  • A session whose host died can be stopped and removed again. When a host stops answering its control socket while its shell is still alive, Stop and Remove now signal that exact child (verified by its recorded start time) instead of failing with an opaque 500, and the error a Controller sees now carries the Host's reason.
  • Paired devices report what they can reach. unpeel pair list says direct + link only when this Host holds Link authority, and a phone's last-seen time advances while it is in use instead of freezing at pairing.
  • Settings ▸ Workspaces lists every workspace you have created, not only the one this instance runs, with or without a license.
  • Returning to Local keeps your selected session. A session created after launch is no longer deselected when you switch back from another Host.
  • OMP (oh-my-pi). The omp agent CLI is recognized with a launch preset, hooks, resume, transcripts, and the unpeel MCP server through Install integration.

Also in 0.7.1

  • Line height. Settings ▸ Appearance ▸ Terminal font has a Line height control (−20 % to +100 %), applied live to every pane.
  • Quick Launch for custom commands. Any command can be starred on Settings ▸ Agents and becomes its own sidebar chip.
  • Agents and Plugins in the new-session menu. The "+" menus list agents and plugins in their own sections, each with its Manage entry.
  • Antigravity CLI. Google's agy is recognized, has a launch preset, resumes with --continue, and gets the unpeel MCP server through Install integration.

Also in 0.7.0

  • Launches are plain; integrations are explicit. A launch command runs in your login shell exactly as typed: nothing is wrapped, no flag is appended, no conversation id is minted, and no agent configuration is edited behind your back. Each agent's hooks and its unpeel MCP registration are now its integration, installed once per account from Settings ▸ Agents (or unpeel integrations install) into the agent's own configuration, shared by every local workspace on the Mac, and kept current by the Host after upgrades. Upgrading from 0.6 keeps your agents connected: hooks Unpeel installed before are adopted as integrations and refreshed on first start. Without it an agent still gets identity and, where the runtime declares screen rules, busy and idle read from the screen; with it you get exact status, done notifications, transcripts, precise resume, and Unpeel's tools inside the agent.
  • Settings: Agents, Plugins, Agent access. One expandable row per agent CLI covers install and update, the integration, launch commands with Quick Launch and reordering, and activation. Unpeel Apps are managed under Plugins. What agents may do through Unpeel's tools — reading and typing into other sessions, the browser, worktrees, the gallery — lives on one Agent access page.
  • The unpeel CLI is a full peer of the MCP server. unpeel mcp reaches every tool and action, and unpeel send / unpeel keys from inside a session follow the same write-approval policy as the MCP server.
  • Agents typed into a blank terminal get transcripts and auto-titles once they report through their integration.
  • Choose Host folders and send files from any Controller. A paired Mac or phone can add a Host folder as a project and move files to a remote session, with every path resolved on the Host inside an explicit scope.
  • Terminal panes run to the window top again while the sidebar is open; the title strip stays for a collapsed sidebar, Settings, and the libraries. The active project's branch now shows beside its name in the sidebar.
  • Fixes. Agent writes in a workspace created after installation no longer fail on a missing approval token. A session created in a sibling workspace appears and is selected at once. A hidden busy pane can no longer deadlock a workspace switch. Muse Code registers the unified MCP server.
  • Host protocol minors 20 and 21, both additive: Host folder selection and file transfer, and integrations.install. Controllers keep checking capability ids, never the minor.
