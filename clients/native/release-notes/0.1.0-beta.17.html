Unpeel 0.1.0-beta.17

  • Unpeel is now free. The full desktop app — unlimited sessions, every agent CLI, updates — costs nothing. Unpeel Pro ($59 per seat per year) covers iPhone remote control (new pairings) and Profiles. Existing phone pairings keep working.
  • Computer use (experimental) — agents can control this Mac's apps in the background: read a window's UI, take screenshots, click, and type, without stealing your cursor or focus. Each session asks you once before its first action.
  • One Unpeel MCP server — Sessions use, Browser use, and Computer use are now domains of a single unpeel server, with matching Settings tabs.
  • New agent CLIs — Kimi, Kimi Code, Cline, and Kiro v3 join the lineup with lifecycle hooks, exact resume, and transcripts.
  • Stop & Resume — a non-destructive Stop verb frees a session's terminal without losing anything; stopped sessions offer Resume and pick up the exact conversation. Idle terminals auto-stop after a day (configurable).
  • Archived sessions library — archived sessions moved out of the sidebar into a dedicated per-project view (right-click a project ▸ Archived): resume, restore, copy transcript, or remove. Archiving is crash-safe.
  • Agents can prep worktrees (opt-in) — an agent can create a git worktree and launch a session inside it; new worktree branches fork from the mainline, not the current checkout.
  • Experimental features are on by default — worktrees, Sessions/Browser/Computer use, and Profiles ship enabled; turn any of them off in Settings ▸ Experimental.
  • Browser access is now Off / Ask each session / Allow, like Computer use.
  • Agent CLI updates: an in-app "Update available" notice with one-click update.
  • iPhone: optional Apple Intelligence cleanup pass for dictation, and the preset drawer now respects your CLI availability choices.
  • Anonymous active-install counting via update checks — a random id and a date, never hardware ids, IPs, or anything joinable to your license.
