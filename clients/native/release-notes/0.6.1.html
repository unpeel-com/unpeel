Unpeel 0.6.1

  • Mac-to-Mac Direct connections work again. Since 0.5.3 a Host refuses device tokens over plaintext /mobile, and the Mac app's own Direct client was still connecting in the clear, so a paired Mac showed "Offline · 426: use https" on 0.6.0. The Mac Controller now dials Direct over TLS pinned to the Host certificate it already trusts, the same way the phone has since 0.5.3. Re-pairing is not needed.
