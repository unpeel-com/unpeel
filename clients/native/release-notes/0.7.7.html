Unpeel 0.7.7

  • The Host stays responsive during long runs. Closed Controller connections now release their finished threads. Previously, those threads retained stack memory until the Host restarted, eventually making session controls time out.
  • Starting and removing sessions works through brief Host reconnects. Terminal controls wait for the selected Host to reconnect before sending the request, instead of immediately reporting "This Host is not connected." Cancelled background refreshes can no longer mark the current connection offline.
  • Resumed agents keep running. Resume now restarts a session's idle clock, so automatic stopping no longer stops a resumed agent seconds after it starts because the session was created long ago.
  • Reattaching preserves the screen layout. Blank rows at the bottom of a terminal snapshot are retained, so older scrollback cannot shift a partially drawn screen when you reconnect.
  • libghostty-vt 1.0. The Host now uses the stable terminal-emulation library on macOS and Linux, with compact terminal storage and no C++ runtime dependency.
