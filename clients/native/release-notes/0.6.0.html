Unpeel 0.6.0

  • Open files and resources with Apps. Cmd-click in a terminal and unpeel open go through one Host-owned opener policy for local, scoped, and remote workspaces: an App, your editor, or the system, per resource kind. A missing official App can be installed on that Host after you confirm, then opens beside the calling Session. Each workspace remembers its own opener choices.
  • Agents can open files beside themselves. Through Unpeel MCP an agent opens a file or typed resource in a companion App pane next to its own Session, with no approval prompt. Agents still never install an App or create, restart, remove, or close a Session.
  • The first-party Apps ship from the Unpeel repository. Markdown, Files, Diffs, and Usage carry versions: Settings and unpeel apps update offer Update when a newer release is published, and App icons appear in the sidebar. Unpeel Design and GitHub Issues left the catalog.
  • Restart App and Reload Terminal keep the Session. A live host is replaced in place under the same Session id, so pins, titles, approvals, and an App's pane binding survive.
  • Force Quit no longer takes your terminals down. The Host service starts through launchd instead of as the app's child, so terminating the app leaves every session host running.
  • Agents & Apps are managed on the selected Host. One settings pane and launch list cover installed agents and Apps for local and remote workspaces alike, with install and update commands running in an embedded terminal on that Host.
  • Hook delivery is reliable under cancellation. A cancelled turn no longer leaves a spinner running, delayed hooks cannot revive it, and missed events are recovered from durable markers.
  • Terminal font setting. Settings ▸ Appearance picks the family and size; Cmd-+ / Cmd-- / Cmd-0 zoom every pane and persist.
  • Built-in computer use has been removed. Desktop tools are configured through your agent or VM environment. Browser use and remote Hosts remain available.
  • Settings ▸ Experimental is now Features; only Browser use is still marked experimental. Sessions are titled after the working tree and branch or the folder being browsed. Scoped workspaces show MCP approval prompts and the full project menu. A Host advertises its workspace name, never the DNS hostname.
