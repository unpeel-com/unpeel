Unpeel 0.1.0-beta.18

  • Computer use engine fix — beta.17 shipped without the bundled computer-use engine, so Settings ▸ Computer showed "engine missing" and computer tools were unavailable. This update includes the engine; no other action needed (grant Accessibility and Screen Recording in Settings ▸ Computer to use it).
  • Fixed the Unpeel Pro price shown in Settings upsells — it's $59 per seat per year, as on the website (the panels incorrectly said $79).
  • Agent CLI update notices no longer float over the app — they live on the Agent CLI tools screen with one-click Update buttons. The session row's Resume/Restart button moved into the hover cluster so pin and archive controls stay put on hover.
