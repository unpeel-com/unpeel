Unpeel 0.7.4

  • ⌘K opens in every workspace. The command palette was reachable only in your main workspace. It now opens in every scope and leads with what is spinning or done across all of your workspaces — the same activity the Recent-activity dropdown shows — and jumping to one of those rows switches to its workspace.
  • Sessions stuck after a full disk can be removed. When the disk filled up, a session could stay running forever with a dead child and no control socket, and "Couldn't remove the session". Such a session now ends cleanly, its exited state lands once space returns, and Remove works. A session whose host stopped answering can also be stopped and removed even when its child can't be verified.
  • Group renames stick. Renaming a sidebar group through the Host survives relaunch instead of reverting.
  • See why a paired Mac is out of reach. When a paired Mac is on another network, the reason now says to use Unpeel Link or set up Tailscale, rather than failing silently.
  • Pairing on iPad. The pairing sheet now presents correctly on iPad.

Also in 0.7.3

  • Approval prompts in every workspace. When an agent in a workspace other than Personal asked to type into another session, the prompt never appeared: the request timed out after two minutes and the agent was told you had declined. Scoped workspaces now show the prompt within a couple of seconds, on the target session's pane, and a prompt nobody answers is reported to the agent as unanswered rather than declined.
  • Your workspace comes back on relaunch. Quitting while scoped to another local workspace reopens in that workspace, the way a selected Host already did.
  • Folder colors in scoped workspaces. Colors chosen on projects of another local workspace now show up (contributed by anilsenay).

Also in 0.7.2

  • OpenCode no longer freezes the app on macOS 15. Starting an opencode session pinned the main thread at 100 % while resolving the OpenCode theme (the config lookup walked past / forever on macOS 15 Foundation) and the app had to be force quit. The lookup is finite now.
  • A session whose host died can be stopped and removed again. When a host stops answering its control socket while its shell is still alive, Stop and Remove now signal that exact child (verified by its recorded start time) instead of failing with an opaque 500, and the error a Controller sees now carries the Host's reason.
  • Paired devices report what they can reach. unpeel pair list says direct + link only when this Host holds Link authority, and a phone's last-seen time advances while it is in use instead of freezing at pairing.
  • Settings ▸ Workspaces lists every workspace you have created, not only the one this instance runs, with or without a license.
  • Returning to Local keeps your selected session. A session created after launch is no longer deselected when you switch back from another Host.
  • OMP (oh-my-pi). The omp agent CLI is recognized with a launch preset, hooks, resume, transcripts, and the unpeel MCP server through Install integration.
